# Contributing to Awesome Forward Deployed Engineering

Thank you for helping make this open-source FDE playbook sharper and more useful for engineers worldwide!

## What Makes a Great Pull Request?
- **Practical Enterprise Patterns:** Real integration patterns (SFTP/ERP bridges, SSO, hybrid RAG, VPC packaging).
- **Realistic Interview Scenarios:** System design prompts rooted in messy enterprise constraints.
- **High-Signal Free Resources:** Official docs, university courses, and open-source tools (no paywalled SEO spam).

## Checklist Before Submitting
1. Check existing files so you don't duplicate an entry.
2. Keep descriptions concise (1–2 sentences explaining *why* an FDE needs it).
3. Ensure all code snippets are syntactically valid and free of credentials or private client details.
4. Format Markdown cleanly and verify relative links.
